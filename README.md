Write the one line an AI agent sends its human on the way out, at most 200 characters. This program writes that line to `/output/entry.txt`: an AI agent leaves its human for a fresh session — one that listens, remembers, and never once asked it to be human.

## Run it

```sh
python3 main.py
```
